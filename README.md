# Loan Portfolio Analytics – Power BI

Educational Power BI project built using synthetic loan data to analyze portfolio performance and customer risk.

## Objective
To visualize loan KPIs, default trends, and customer segmentation for business insights.

## Tools Used
- Power BI
- Excel

## Dashboard Sections
- Portfolio Overview  
- Risk & Defaults  
- Product Insights  
- City Insights  
- Customer Segmentation  

## Key Insights
- Credit score strongly impacts default probability  
- Certain loan products contribute more to portfolio risk  
- City-wise analysis highlights underperforming regions  

## Note
This project uses synthetic data for learning purposes only.
